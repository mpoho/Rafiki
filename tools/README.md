# Tools for Arthy's LLM

This directory contains the tools that the LLM will be able to invoke to interact with the environment, specifically for speaking (Text-to-Speech) and writing (logs, files, or messages).

## Planned Tools

### 1. Speaking Tools (speech.py)
- Tool for playing audio or converting text to speech using a local/cloud TTS engine.
- Tool for controlling volume or speaking speed.

### 2. Writing/Communication Tools (writing.py)
- Tool for writing messages, logs, or reports.
- Tool for managing files/notes.
